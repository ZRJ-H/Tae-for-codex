# 花园多惠 · Tae for Codex

以 BWIKI 游戏 SD 小人为造型参考的轻像素风花园多惠宠物素材，保留蓝白演出服和蓝色吉他。

[下载 v1.0.0 素材包](https://github.com/ZRJ-H/Tae-for-codex/releases/tag/v1.0.0)

## 使用

下载 Release 中的 `hanazono-tae-v1.0.0.zip` 并解压，将 `spritesheet.png` 提供给支持自定义图集的 ChatGPT Pets 工作流，要求验证、创建并选用。可以附上图片后说明：

> 请使用这张已经制作好的 v2 精灵图创建并选用“花园多惠”宠物，先验证图集，保留现有画面和动画。

这是宠物动画素材包，不包含独立 Windows 桌宠程序或安装器。`manifest.json` 是图集规格说明，不是独立程序的安装配置。

## 动作与规格

- 九组基础动作：待机、向右移动、向左移动、挥手、跳跃、失败、等待、拨弦工作、检查琴弦。
- 16 个视线方向：从正上方开始，顺时针每 22.5° 一帧。
- 透明 RGBA PNG：1536 × 2288；8 列 × 11 行；单格 192 × 208。
- 每行有效帧数：`6, 8, 8, 4, 5, 8, 6, 6, 6, 8, 8`，其余 15 格透明。

## 文件

| 文件 | 内容 |
| --- | --- |
| `spritesheet.png` | 可供导入的最终图集 |
| `manifest.json` | 版本、布局及图集 SHA-256 |
| `preview/` | 各动作 GIF、视线循环、跳跃衔接、MP4 与静态示例 |
| `contact-sheet.png` | 全部动画帧总览 |
| `directions.png` | 16 方向检查图 |
| `validation/` | 结构、质量与独立方向审查记录 |
| `SHA256SUMS.txt` | 发布素材的校验值 |

## 验证与已知细节

图集结构、透明背景、帧数、最终质量检查和 Pets 服务预检均通过。跳跃离地 44 像素，落地基线与待机一致；视线中心最大偏移 3 像素。四个主要方向通过三份独立盲审。

部分相邻斜向姿势变化较细；112.5° 斜右下的低头幅度在单帧盲审中较难辨认，完整循环检查后保留并记录。详见 `validation/`。
