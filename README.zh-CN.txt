使用
spritesheet.png 是通过 Pets 服务预检的 v2 图集。将文件提供给支持自定义图集的 ChatGPT Pets 工作流，要求验证、创建并选用即可；创建时会为使用者生成新的宠物 ID。
此 ZIP 是动画素材包，不包含独立 Windows 桌宠程序或安装器。manifest.json 用于说明图集布局，不是某个独立桌宠程序的安装配置。

图集规格
1536×2288 RGBA PNG；8列×11行；单格192×208。每行有效帧数为6、8、8、4、5、8、6、6、6、8、8，其余格透明。
基础动作：待机、向右移动、向左移动、挥手、跳跃、失败、等待、工作（拨弦）、检查。
最后两行是从向上开始、顺时针每22.5度一个姿势的16方向视线。
